# ふるさと納税 市区町村分析ダッシュボード（5年推移・データ完全内蔵版）

## 開き方

1. ZIPを展開します。
2. `index.html` をダブルクリックします。
3. 地図上部の「表示年度」で令和2～6年度を切り替えます。
4. 「5年推移」タブで自治体を選択すると、寄附受入額と実質収支額の推移、前年度比、5年増減率を確認できます。

`open_dashboard.bat` をダブルクリックして開くこともできます。

## 実装内容

- 添付された元コードをそのまま基礎として使用
- 令和2～6年度の全1,741市区町村の値を `index.html` 内に固定
- 実行時にExcel、CSV、JSONを取得しない
- 地図の年度切替
- 自治体詳細の寄附受入額グラフ
- 自治体詳細の実質収支額グラフ
- 前年度比と5年増減率
- 最新年度における元コードの上限付き簡易推計表示を維持
- 令和5年度の削除済み総務省原表は、Wayback Machineの2024年8月28日保存版から同一ファイルを回収し、ハッシュを記録

## 実質収支額の定義

5年間を同じ条件で比較するため、次の共通算式を使用します。

```
寄附受入額
－ 募集に要した費用
－ 被災地方団体の代理受入額
－ 翌年度課税の住民税控除額
＋ 住民税控除額 × 75％
```

これは年度間比較用の制度値です。自治体別の普通交付税増加額の直接実績や自治体決算上の実質収支を示すものではありません。令和6年度については、元コードに含まれていた普通交付税決定額を上限とする簡易推計も別指標として残しています。

## ファイル構成

- `index.html`：配布用の単一HTML。5年度分の全値を内蔵
- `reference/original.html`：今回の基礎とした添付元コード
- `data/source_manifest.json`：出典URL、SHA-256、年度、件数
- `scripts/validate_repository.py`：内蔵件数、コード、算式、最新年度一致を検証
- `open_dashboard.bat`：Windows用起動補助

## 検証

Python 3がある環境では、リポジトリ直下で次を実行できます。

```bash
python scripts/validate_repository.py
```

正常時は `VALIDATION OK` と表示されます。

## 通信について

金額データはすべてHTML内蔵です。地図表示だけは、元コードと同様にMapLibre、PMTiles、国土地理院タイル等の外部配信を利用します。通信できない場合でも「5年推移」タブの金額・グラフ・増減率は表示できます。
